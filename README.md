# Miss Direction

A co-op physics party game for 1 to 10 players. You and your friends are trapped in Madame Direction's cursed carnival funhouse and have to climb 30 floors to escape. At the start of every floor, a fortune-teller machine prints each player a **Fortune**: inverted controls, an upside-down screen, blindness, a reversed voice, or (sometimes) something good. Then the whole team has to reach the elevator together.

Full design: see the Miss Direction Game Design Document.

## Status

Early prototype, single player, no networking yet. What works today:

- First-person physics movement: walk, sprint, jump, look.
- Two-handed grabbing: carry objects, hold a teammate's hand, press buttons.
- Data-driven Fortunes made as assets, with 12 starter Fortunes.
- The Fortune Machine: one press at a time, red or gold reveal, printed card, out-of-turn shock.
- Vision effects: Upside Down, Mirror, Blind.

## Getting started

See [docs/SETUP.md](docs/SETUP.md) for cloning with GitHub Desktop and turning this folder into a Unity project. Once it's open in Unity:

1. Top menu **Miss Direction → Build Test Playground Scene**.
2. Press **Play**.
3. Walk to the machine and **left-click the button** to draw a Fortune, then **left-click the card** that pops out to take it.

| Action | Input |
| --- | --- |
| Move | WASD |
| Look | Mouse |
| Jump | Space |
| Sprint | Left Shift |
| Grab left / right hand | Hold left / right mouse |
| Ping | Middle mouse (not wired up yet) |

## Project layout

```
Assets/_Project/
  Scripts/
    Fortunes/      FortuneDefinition, FortuneDeck, FortuneMachine, FortuneCard, effects
    Player/        Controller, input, grabbing, modifiers, screen effects
    Interaction/   IInteractable (buttons, cards, levers)
    Editor/        "Miss Direction" menu: starter Fortunes and the test playground
  Data/Fortunes/   Fortune and deck assets (generated by the menu)
  Prefabs/         FortuneCard and, later, players and floors
  Scenes/          Playground and, later, floors
  Art/  Audio/     Models, textures, sounds (stored with Git LFS)
```

## Making a new Fortune

1. In the Project window: **Create → Miss Direction → Fortune**.
2. Fill in the name, card rule, kind (Bad, Good, Mixed, Role) and cap.
3. **Create → Miss Direction → Effects → Modifier Effect**, pick a modifier (invert, flip, delay, gravity...) and add it to the Fortune's Effects list.
4. Add the Fortune to `StarterDeck`.

Fortunes that need brand-new behavior (voice filters, the Navigator's map, Giant) get a new `FortuneEffect` subclass.
